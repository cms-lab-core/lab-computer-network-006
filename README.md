# Computer Networks 006

Лабораторная **«IPv4: адрес, сеть и префикс»**. Исследуем, как `/24 → /25` на одном Linux host меняет connected route и вызывает асимметричное представление о локальной сети, несмотря на тот же Ethernet. Два настоящих захвата ARP/ICMP, контролируемый отказ, восстановление и VLSM.

Материалы: `task/task.ipynb`, topology и рисунки в `task/assets/`. Management `eth0` не меняем.
